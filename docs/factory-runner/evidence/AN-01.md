## Red

The initial contract test commit `9cb024a` failed because the v1 model,
protocol, schema, and fixture surfaces did not yet exist. Schema conformance
tests were then committed separately in `2dab0eb` before the checked-in
artifacts existed.

Independent adversarial review added a consolidated boundary selection covering
schema/model parity, checkpoint operation and verification-input binding,
evidence coherence, changed-file source uniqueness, ordered public inputs,
stable large-number errors, and nested-instance revalidation. Before
remediation, that selection reported 25 failed and 3 passed.

A final nested durable-JSON regression was committed separately as `9fde06a`.
Its focused Red command was:

```bash
docker compose run --rm workspace uv run pytest -q \
  tests/factory_runner/contract/test_protocol_additional_rules.py \
  -k nested_frozen_json_subdocuments
```

Result: two expected failures. Nested lists and mappings had already been
frozen, but revalidation accepted only mutable JSON containers.

A final provenance audit reproduced a verify checkpoint that retained
authoring-stage authority and history while still passing model, schema,
self-digest, and resume compatibility. The model and independent-schema Red
selection was:

```bash
docker compose run --rm workspace uv run pytest -q \
  tests/factory_runner/contract/test_contract_semantics.py::test_verify_checkpoint_preserves_verify_only_origin \
  tests/factory_runner/contract/test_schema_artifacts.py::test_checkpoint_schema_binds_verify_only_stage_authority_and_history
```

Result: four expected failures before checkpoint provenance was bound.

artifact, command, and immutable-JSON types. Generated schemas are derived
from the models with one command. Contract imports remain lazy at workflow and
control-plane boundaries.

provenance selection passed 4/4. The complete contract suite then passed:

## Assumptions and residual risks

- AN-02 must implement bounded non-interactive execution against these
  contracts; AN-01 does not execute commands.
- AN-03 must verify actual filesystem state, artifact bytes, deterministic
  patch generation, event production, and clean-verification isolation.
- AN-04 owns release compatibility certification, OCI publication, and the
  formal release receipt. This AN-01 wheel is a smoke artifact, not a release.
- Any breaking change to the frozen v1 wire or semantic rules requires a new
  protocol major version.

AN-02 must not begin until all required automated checks and machine-verifiable
AN-01 evidence pass, the trusted publisher enables protected GitHub auto-merge,
and GitHub reports the resulting merge commit as the exact default-branch HEAD.
