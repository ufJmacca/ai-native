## Review red and green

Policy-ceiling review reproduced constructor widening against pre-fix commit
`db90586`:

```bash
python3 -c 'from ai_native.factory_runner.policy import ExecutionCapability, FactoryModeCapabilities; policy = FactoryModeCapabilities(allowed=frozenset({ExecutionCapability.COMMIT})); assert not policy.permits(ExecutionCapability.COMMIT), "factory policy constructor widened authority"'
```

Result: failed with the expected
`AssertionError: factory policy constructor widened authority`. After making
the policy fields non-configurable, the focused immutability regression test
passed 1/1.

Independent review also reproduced two compatibility gaps before remediation:

- `ainative factory run --help` exited 0 instead of rejecting the unavailable
  subcommand;
- refactoring removed the legacy `run_projection.SLICE_PIPELINE` export and
  changed `slice_runtime.SLICE_SPECIFIC_STAGES` from `set` to `frozenset`.

The final factory suite rejects reserved subcommands even when followed by
help, and characterises both legacy exports. It passed 23/23.
